# API & DB 01 — Proxy Serveur Express (`server.ts` & `src/app/api/`)

- `GET /api/health` : État de santé et présence de `GEMINI_API_KEY` côté serveur.
- `POST /api/oracle/dossier` : Proxy serveur `@google/genai` validé par `EventGeneratorRequestSchema` + `parseGeminiDualPass` + fallback déterministe.
- Port d’écoute : `3000` avec `vite.middlewares` en développement et `dist/` en production.
