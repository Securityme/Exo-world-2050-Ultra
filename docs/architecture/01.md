# Architecture 01 — Stratification SSoT `L0..L8` & Shell Astralis v3.0

## 1. Couches Logicielles Strictes (`eslint.config.mjs`)

- **L0 (`contracts/`, `parsers/`)** : Schémas Zod canoniques (`WorldState`, `SceneDiffPacket`, `TriggerBus`, `PaDossiers`, `CombatUnits`) et parseurs Result Pattern `[ExwError, null] | [null, T]`.
- **L1 (`config/`, `data/`)** : Constantes `Object.freeze` et catalogues déterministes `R-50`.
- **L2 (`core/`, `guardrails/`)** : Noyau 100 % pur sans I/O (`Pcg32`, `sha256Hex`, triggers, queues, dispatchers, routers, cycle orchestrator `N0→N5`, 5 garde-fous).
- **L3 (`systems/`)** : Systèmes métier purs (Biosphère `P1→P4`, PA & Dossiers, Économie Anno 3-Modules, Combat 4 phases & Cyber).
- **L4 (`engine3d/`, `adapters/`, `bridges/`)** : Adaptateur de rendu Three.js r170+ (3 échelles PBR/Solarpunk) et pont IPC Unity 6 URP V5.
- **L5 (`retrievers/`, `stores/`, `services/`, `pipelines/`, `worker/`, `doc-sync/`)** : État Zustand/Jotai, Web Worker, Firebase Auth/Firestore, Sauvegardes locales, Audio Radio FIP, Oracle Gemini.
- **L6 (`hooks/`, `handlers/`)** : Hooks React (`useRuntimeStackStatus`, `useViewportLayout`, `useOracleDossierMutation`) et handlers Result Pattern.
- **L7 (`components/`, `interfaces/`, `features/`)** : EXO-SHELL Rose & Blanc Astralis, 3 hubs primaires (`Mondes`, `Événements`, `Journal`), `Profil`, `Paramètres` (incluant Studio Documentaire, Atlas Blueprint & Fonctionnalités).
- **L8 (`app/`, `server.ts`)** : Point d'entrée Express + Vite port `3000` exposant `/api/system-status`, `/api/oracle/dossier`, `/api/docs/*` et le flux audio `/api/audio/fip`.

## 2. Ergonomie de l'Écran de Jeu (`GameHud` & `SubscreensOverlay`)

| Zone | Composants | Rôle UX |
| --- | --- | --- |
| **Header** | Télémétrie (`Ère`, `Cycle`, `Atmosphère`, `Crédits`, `PA`) · Échelles `1/2/3` · `Masquer/Ouvrir UI` · `Radio FIP` · `Profil` · `Paramètres` · `Pause` | Pilotage permanent sans encombrer la scène 3D |
| **Footer Dock** | Bandeau Dossiers exécutifs (extensible **Compact ↔ Plein Écran**) + **3 onglets primaires uniquement** (`Mondes`, `Événements`, `Journal`) | Zone pouce mobile-first & vue d'ensemble desktop |
| **Menu Principal** | Voyants temps réel sondant `package.json` (`/api/system-status`), Three.js, Firebase, TanStack, Zustand/Zod et API | Transparence technique instantanée avec infobulles |
