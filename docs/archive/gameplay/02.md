# Gameplay 02 — Biosphère Open-Sky (`P1 → P4`) & Maintenance `C3`

- **Paliers** : `P1 Hostile` (kits respiratoires requis), `P2 Stabilisé` (`≥ 33 %`), `P3 Respirable` (`≥ 66 %`), `P4 Éden` (`≥ 92 %`).
- **Règle Open-Sky (`R-16`)** : Aucun dôme clos ; périmètres protégés par pylônes ioniques.
- **Watchdog `C3`** : Intégrité `< 25 %` émet un événement `P0_CRISIS` sur `TRIGGER_BUS`.
